Privacy policy

Last updated: 23 November 2026

rclone-avi is used by one person only: its owner, to reach their own Google Drive from their own computer.

What data it accesses

With the owner's consent, it accesses the owner's Google Drive files through the Google Drive API so they can be shown as a local drive.

Where the data goes

Files and sign-in tokens stay on the owner's own computer. Nothing is sent to any server other than Google's. No data is collected, sold, shared or used for advertising.

Google API Services User Data Policy

rclone-avi's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/connections.
